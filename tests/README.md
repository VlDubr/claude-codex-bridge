# Тесты

```bash
node tests/regressions.mjs
```

119 тестов, по одному на каждый дефект, найденный в ревью. Настоящие `codex` и
`claude` не нужны: всё окружение — заглушки, которые тест создаёт сам во
временном каталоге, а их поведение задаётся переменными окружения.

28 тестов требуют POSIX: заглушки — shebang-скрипты, которые Windows запустить
не может, а права `0600` и кавычки в именах файлов там ничего не значат. На
Windows они помечаются пропущенными, а не выдаются за пройденные; проходит 91.
Тест утечки дескрипторов дополнительно требует `/proc` и вне Linux пропускается.

CI гоняет набор на Linux и Windows против Node 20.11 и 22
(`.github/workflows/tests.yml`), поэтому POSIX-часть не остаётся непроверенной.

Файл намеренно один и без раннера — чтобы не заводить зависимости. Новую
функциональность сопровождайте тестом здесь же.
